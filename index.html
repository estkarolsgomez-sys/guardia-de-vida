Cómo jugar

Gráficos V15: selecciona Ultra HD o Cinemática en Ajustes. La sala cuenta con cirujano, enfermera, paciente, lámparas, monitor y ropa de alta definición. La mejor experiencia es en pantalla horizontal. Zoom visual: acércate al médico para ver su cara y detalles.

Celular: arrastra el joystick izquierdo para caminar; arrastra en cualquier zona libre de la escena para mirar (los toques cortos seleccionan). Pulsa sobre los instrumentos, dirige la cámara al círculo luminoso y utiliza USAR.

Manos: Señala la pantalla con el índice y cierra la pinza índice-pulgar, después suelta para hacer clic. Mantén la pinza y desplaza la mano por el fondo para girar la vista. Puedes reiniciar o cambiar la cámara desde la vista previa. Si no hay cámara, los controles táctiles siguen funcionando. usa REINTENTAR CÁMARA si no aparece vídeo. Muestra una mano iluminada y haz pinza con índice y pulgar sobre el instrumento o sobre la zona de interacción. Si no se detectan correctamente, puedes seguir tocando la pantalla. Para retroceder usa el joystick hacia abajo; con pasos físicos pulsa «Pasos: RETROCEDER» antes de dar los pasos, ya que el acelerómetro no identifica por sí solo el sentido.

VR de celular: Antes de poner el visor, activa el sensor y ajusta la separación de ojos. Pulsa ENTRAR AL VISOR para esconder los controles. El círculo de mirada en 3D se llena para seleccionar; también puedes usar el gatillo de pantalla o botón A del mando. la pantalla se divide para un visor tipo Cardboard. Activa el sensor desde el botón de VR. El giroscopio orienta la vista cuando el navegador lo permite. Para avanzar inclina ligeramente la cabeza hacia abajo, mantén CAMINAR o usa un mando Bluetooth; sin sensor puedes arrastrar para mirar. No es seguimiento espacial 6DoF.

Teclado: WASD para caminar, ratón para mirar, E para interactuar, Q o 1–5 para seleccionar instrumentos.

Para cámara o giroscopio, algunos navegadores exigen HTTPS o permisos adicionales. Si se bloquean, los mandos táctiles siguen disponibles. En Android se recomienda Google Chrome actualizado. Las estadísticas clínicas son ficticias.
